# Program 2 – Grocery Bill Generator

## Description

A C++ program that displays a grocery bill for Mega Mart, including a list of purchased items, their quantities, unit prices and total prices.

## Features

- Displays 30 grocery items.
- Shows item quantities and unit prices.
- Calculations are represented in the bill through predefined values.
- Displays subtotal, 9% discount and total payable amount.
- Generates a formatted shopping bill.

## Concepts Used

- `iostream`
- `cout` statement
- `endl`
- Escape sequences and formatting
- Basic program structure

## Input Requirements

This program does not require user input. All grocery items, prices, quantities and bill calculations are predefined in the source code.

## Note

The bill is displayed using predefined information rather than accepting purchases dynamically from the user.
