# Program 1 – Student Information Display

## Description

A simple C++ program that displays student information in the console.

## Information Displayed

- Student Name
- F.Sc Marks
- Department
- Semester
- University Name

## Concepts Used

- `iostream`
- `cout` statement
- `endl`
- Basic program structure

## Input Requirements

This program does not require user input. All student information is already written in the source code.

## Note

This is a basic output-based program designed to demonstrate displaying information using C++.
