# Program 3 – Student Result Card Generator

## Description

A C++ program that collects student information and marks in five subjects and generates a formatted university result card.

## Features

- Accepts student's first and last name.
- Accepts roll number.
- Takes marks in five subjects:
  - Programming Fundamentals
  - English
  - Mathematics
  - Physics
  - ICT
- Calculates total obtained marks.
- Calculates percentage.
- Displays a formatted student result card.

## Concepts Used

- Variables and data types
- String handling
- User input using `cin`
- Arithmetic operators
- Basic calculations
- Output formatting

## Input Requirements

- First Name: Text
- Last Name: Text
- Roll Number: Integer
- Subject Marks: Integers

**Important:** Each subject has a maximum of 100 marks. Enter marks between 0 and 100 for each subject. The total maximum marks are 500.

Do not enter text in numeric fields or marks outside the expected range, as the program does not implement input validation.
